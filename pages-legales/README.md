# Pages légales — Vyrae

Modèles prêts à coller dans Shopify. **Ce sont des modèles, pas un conseil juridique** :
remplace tous les champs entre crochets `[...]` par tes vraies informations, et fais
relire par un professionnel si tu as un doute (surtout pour la TVA et les CGV).

## Où les coller dans Shopify

| Fichier | Emplacement Shopify |
|---|---|
| `politique-de-confidentialite.md` | Paramètres → Politiques → Politique de confidentialité |
| `politique-de-remboursement-et-retours.md` | Paramètres → Politiques → Politique de remboursement |
| `politique-d-expedition.md` | Paramètres → Politiques → Politique d'expédition / d'achat |
| `conditions-generales-de-vente.md` | Boutique en ligne → Pages → Ajouter une page (« CGV ») |
| `mentions-legales.md` | Boutique en ligne → Pages → Ajouter une page (« Mentions légales ») |

Les pages de **Politiques** génèrent automatiquement leur lien (`/policies/...`).
Pour les **CGV** et **Mentions légales**, crée une page puis ajoute son lien au menu de
pied de page (Boutique en ligne → Navigation → menu choisi dans la section « WLD — Vyrae Landing »).
